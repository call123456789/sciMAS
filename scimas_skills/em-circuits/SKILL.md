# EM Circuits

Use this skill for DC resistive circuits: series and parallel combinations, Wheatstone-bridge balance, and Ohm's-law problems.

Report the supply voltage and the galvanometer / load resistance when computing bridge imbalance. Note that all resistors must be > 0 for parallel combination.

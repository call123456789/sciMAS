# CM Anderson And Topological

Use this skill for disorder-driven Anderson localization in 1D and SSH-chain topological band-structure properties.

Specify the disorder strength W and the system size. For SSH, report intra-cell (v) and inter-cell (w) hopping signs and the resulting winding number ν.

# EM Magnetic Fields

Use this skill for magnetic-field strength from current configurations, force between parallel currents, magnetic moment of a current loop, and B-H curve / relative permeability.

Distinguish attractive (currents in same direction) vs. repulsive (opposite) forces for parallel wires. Always state the relative permeability classification (ferromagnetic, ferrimagnetic, paramagnetic, diamagnetic).
